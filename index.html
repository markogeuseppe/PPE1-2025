Miniprojet : Analyse automatique d’un ensemble d’URL Introduction Dans le cadre de ce miniprojet, nous avons développé un script Bash capable d’analyser automatiquement une liste d’URL et d’en extraire plusieurs informations. L’objectif était de mettre en place un petit outil simple, mais complet, permettant de tester l’accessibilité de différentes pages web, d’en récupérer les métadonnées principales, puis de présenter le tout sous forme d’un tableau HTML consultable dans un navigateur. Le résultat final est un fichier HTML généré automatiquement par le script, qui affiche sous forme de tableau les valeurs collectées pour chaque URL. Vous pouvez consulter ce tableau en cliquant ici. Description du fonctionnement du script Le script prend exactement un argument, qui correspond au fichier contenant la liste d’URL à analyser. Chaque ligne de ce fichier est traitée séparément, ce qui permet de récupérer les types d’informations suivants : • Le numéro de ligne, permettant un repérage simple dans le tableau • L’URL elle-même, pour référence • Le code HTTP retourné par la page (par exemple : 200, 404, 301…) • Le type d’encodage de la page (charset utilisé) • Le nombre de mots présents dans le contenu de la page Pour effectuer cette collecte et structurer le traitement, le script utilise plusieurs outils : • validation d’arguments • curl, pour récupérer l’en-tête HTTP et suivre d’éventuelles redirections • lynx, pour extraire le texte brut d’une page HTML • wc, pour compter le nombre de mots • boucle while • variables Une fois ces informations extraites, le script génère automatiquement un document HTML contenant un tableau. Chaque ligne du tableau correspond à une URL du fichier d’entrée. Structure et output Le fichier HTML produit comprend : • une structure minimale (, , ) • un tableau présentant toutes les URL analysées • les colonnes suivantes : numéro, URL, code, encodage, nombre de mots Le résultat final est lisible sur n’importe quel navigateur et offre une vue synthétique de l’état des différentes pages web étudiées. Conclusion Ce miniprojet nous a permis de manipuler plusieurs outils importants de l’environnement Unix (shell, curl, lynx...), mais aussi de comprendre comment automatiser l’analyse de pages web. Le script se veut simple, mais il rassemble toutes les étapes essentielles : lecture d’un fichier, récupération d’informations, traitement des données et génération d’un résultat visuel.
