Miniprojet : Analyse automatique d’un ensemble d’URL

Introduction

Dans le cadre de ce miniprojet, nous avons développé un script Bash capable d’analyser automatiquement une liste d’URL et d’en extraire plusieurs informations. L’objectif était de mettre en place un outil simple, mais complet, permettant de tester l’accessibilité de différentes pages web, d’en récupérer les métadonnées principales, puis de présenter le tout sous forme d’un tableau HTML consultable dans un navigateur.

Le résultat final est un fichier HTML généré automatiquement par le script, qui affiche sous forme de tableau les valeurs collectées pour chaque URL.

Vous pouvez consulter ce tableau en cliquant ici.

Description du fonctionnement du script

Le script prend exactement un argument, qui correspond au fichier contenant la liste d’URL à analyser. Chaque ligne de ce fichier est traitée séparément, ce qui permet de récupérer les types d’informations suivants :

  1. Le numéro de ligne
  2. L’URL analysée
  3. Le code HTTP retourné (200, 404, 301…)
  4. Le type d’encodage (charset)
  5. Le nombre de mots présents dans la page

Pour effectuer cette collecte, le script utilise plusieurs outils :

  • validation d’arguments
  • curl pour les en-têtes et redirections
  • lynx pour extraire le texte
  • wc pour compter les mots
  • boucle while
  • variables Bash

Une fois ces informations extraites, le script génère automatiquement un tableau HTML contenant les résultats.

Structure et output

Le fichier HTML produit comprend :

  • une structure minimale (html, head, body)
  • un tableau regroupant toutes les URL analysées
  • les colonnes : numéro, URL, code HTTP, encodage, nombre de mots

Le résultat final est lisible sur n’importe quel navigateur et offre une vue synthétique des pages étudiées.

Conclusion

Ce miniprojet nous a permis de manipuler plusieurs outils de l’environnement Unix (shell, curl, lynx...), mais aussi de comprendre comment automatiser l’analyse de pages web. Le script regroupe toutes les étapes essentielles : lecture d’un fichier, récupération d’informations, traitement des données et génération d’un résultat visuel.
